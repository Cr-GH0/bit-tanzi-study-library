# 比特毯子 · 视频学习资料库

基于 B 站 UP 主 [比特毯子](https://space.bilibili.com/3546740397443899) 的视频整理的非官方学习资料，便于检索、复习及 Agent 入门分享会备课。

**研究快照：2026-11-15。** 覆盖当次主页全部三页、113个不同BV号，总时长9小时52分02秒；不是持续同步的最新目录。

## 从这里开始

- [学习总览](交付/学习总览.md)：主题脉络、方法与学习路径。
- [逐视频学习笔记](交付/逐视频学习笔记.md)：113条视频的来源、摘要、时间点及核查提示。
- [字幕状态与待补清单](交付/字幕状态与待补清单.md)：7条缺口及3组重复字幕。
- [全部视频目录 CSV](交付/全部视频目录.csv)：可用 Excel 打开。
- [结构化知识库 JSON](交付/视频知识库.json)：供程序检索与二次整理。
- [下载离线资料包](比特毯子-视频学习库.zip)：解压后用浏览器打开 `打开知识库.html`，可搜索、筛主题和待补条目。

GitHub 文件预览不会运行 HTML。也可下载整个仓库，然后双击 `交付/打开知识库.html`，无需安装工具。

## 覆盖情况与阅读方法

- 106条投稿已通读平台中文AI字幕，约16.4万字符；对应103份不同字幕正文。
- 7条未取得可读字幕，仅核对标题及简介，不能当作已经完成内容学习。
- 笔记是原创摘要及近似时间点定位，不是逐字字幕。AI字幕未经逐字对照音轨校正。
- 本次没有逐帧观看所有视频，也没有实测或复现全部工具。作者观点、工具演示与未验证事项请结合每条“核查提示”阅读。
- 早期方案可能被后续视频修正：例如早期记忆Skill的向量数据库接入，以及世界书深度解释，参见学习总览。

## 文件组织

- `交付/`：适合直接阅读、搜索及导入的最终成果。
- `catalog.json`、`catalog-part*.json`：合并目录及三页采集目录。
- `inventory.json`：视频元数据、分P信息、字幕可用性及字数统计。
- `notes-*.json`：逐批整理的摘要、时间点和核查提示源数据。
- `build-library.mjs`：从上述数据重新生成知识库、CSV、逐视频Markdown、HTML和待补清单。
- `read-batch.mjs`：研究时使用的本地字幕分段阅读辅助脚本，需要自行准备字幕JSON。

浏览器探索过程中的一次性会话脚本不属于可复用工具，未收录。完整视频、音频、逐字字幕缓存以及作者提到的第三方软件本体不在本仓库；请通过原视频及作者说明获取。

## 重新生成

使用 Node.js 18 或更高版本，在仓库目录执行：

```bash
node build-library.mjs
```

无需安装依赖。重复字幕分组复用已记录的全文SHA-256比对结果，生成时不需要原始字幕缓存。运行会更新生成数据的时间；原研究快照日期仍为2026-11-15。`学习总览.md`为单独撰写，脚本不重写它；ZIP是已交付的研究快照，不随此命令更新。

`read-batch.mjs` 仅供已有本地字幕JSON的维护者使用：设置环境变量 `SUBTITLE_DIR` 后，执行 `node read-batch.mjs 1 10`。它不会自动抓取字幕。文件名应为 `<BV号>.json`，结构为 `{title, description, parts: [{page, duration, language, available, body: [{from, content}]}]}`。
